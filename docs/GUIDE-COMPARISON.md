# 与 weeazn 官方教程的对照

对照对象：[weeazn 的主题合集下载及问题解答](https://www.kdocs.cn/l/cuXTjG62IqXw)
与其在线向导 [weeazn.xcdream.com](https://weeazn.xcdream.com/)
（weeazn 就是本仓库一直在测的那个 ColorOS 主题的作者）。

**结论先说**：主流方法与本项目**目的一致但路径不同**，其中 ColorOS 一条我们已经实测跑通；
**荣耀那一条我原来的说法有误，已修正**（见第二节）。

---

## 一、逐平台对照

### ColorOS / realme（OPPO / 一加 / 真我）

| | weeazn 教程 | 本项目 |
|---|---|---|
| 适配范围 | ColorOS 11–17；realme 用 ColorOS 主题（RealmeUI 7.0=ColorOS16、6.0=15、5.0=14） | 与之一致：体检会校验 `EditorVersion` |
| 主用方法 | **替换法**（15–17）/ **停用法**（11–14） | **直接投递** `ThemeApplyService`（等于点「应用」） |
| Shizuku 方案 | 空文件替换法（全版本）、雹冻结法（11–14） | 用 shell/root 身份投递 |
| Root 方案 | 雹冻结法（11–16.1）、MCTGA（17 推荐给 root） | 自动解冻 `:applyTheme` 进程 |
| 核心诉求 | 免费试用付费主题 + **防「掉主题」** | 把**本地任意包**应用到系统 |

**关键区别**：他的方法围绕"试用 + 冻结商店防止回滚"；本项目绕开 UI 直接投递。

两者**不冲突，而是互补**：

- 本项目解决"包怎么进系统"（他教程里对应的是手点「免费试用/应用」那一步）
- 他教程解决"进去以后怎么不被商店回滚"——**这一点本项目也需要**：
  如果系统后台校验导致掉主题，仍需按他的方式冻结/停用商店

**理论上行不行**：已经在**他自己的主题包**上端到端验证过——
UUID 切换、`/data/theme` 七个模块落盘、`apply success` 都成立。
所以不是理论推演，是实测。

### 荣耀 / 华为

| | weeazn 教程 | 本项目（修正后） |
|---|---|---|
| 华为适配 | EMUI 10/11、鸿蒙 2/3/4；**鸿蒙 5.0+ 不能用** | 一致 |
| 荣耀适配 | MagicUI、MagicOS 7–11；**要用鸿蒙主题文件（`.hwt`）** | **已按此修正** |
| 版本映射 | MagicUI→鸿蒙2、MagicOS 7→鸿蒙2、MagicOS 8→鸿蒙3、MagicOS 9/10→鸿蒙4 | 体检会提示对应关系 |
| 格式 | 第三方主题走 `.hwt` | `.hwt` 为主；`.hnt` 只当扩展名兼容 |

**我原来的说法需要修正**：我此前依据荣耀社区帖子写过"新荣耀用 `.hnt`"。
按作者的说法，**`.hnt` 是荣耀官方主题编辑器导出的格式**，而**第三方主题应当用鸿蒙 `.hwt`
并按 MagicOS 版本选**。所以 `.hnt` 只是"能识别"，不该当成推荐路径。

### 小米 / 红米 / 黑鲨

| | weeazn 教程 | 本项目 |
|---|---|---|
| 适配 | MIUI 13/14、澎湃 1.0–4.0；MIUI 11/12/12.5 不推荐 | 探测 + 体检 |
| 工具 | **ThemeKit / ThemeStore / HyperTheme**（都需 Shizuku） | **注入商店自己的 Theme backup**（另一条路） |
| 版本 | 澎湃 3 必须用 3.0 主题；澎湃 4 用对应版本 | 体检会报结构差异 |
| 注意 | 澎湃必须关掉主题壁纸/主题商店/桌面的自动更新，否则可能开不了机 | 已写入文档警告 |
| 黑鲨 | JoyUI 13 同小米但**必须 root** | 未覆盖 |

**差异**：社区主流是 Shizuku 直写系统主题目录；本项目走"改商店自己信任的 backup"，
理论上更不容易被版本适配打断，但**未在真机验证**——这点务必看清。

### vivo / iQOO

| | weeazn 教程 | 本项目 |
|---|---|---|
| 适配 | OriginOS 4/5；**OriginOS 6 起不支持** | 探测 + 体检 |
| 前提 | 2023 年后机型、≥OriginOS 4、**必须能卸载 i主题与 vivo 文档** | 路由前需确认 |

两边结论一致：vivo 这条路被官方堵得很紧，作者本人都不做了（社区反馈还提到律师函）。

### 三星 / 魅族

指南未提供支持（评论区有人在求 One UI 适配）。与本项目结论一致：不做。

## 二、这份对照带来的三处修正

1. **荣耀**：第三方主题用 `.hwt` + MagicOS→鸿蒙版本映射；`.hnt` 仅作扩展名兼容，不是推荐路径。
2. **ColorOS**：补上"防掉主题"这一环——投递成功不等于不会被回滚，
   必要时仍需按教程冻结/停用商店。本项目新增了这条提示。
3. **vivo**：补上前提——机型年份、OriginOS 版本、以及"能否卸载 i主题"。

---

## 三、本项目相对教程的价值在哪

教程解决"**用作者的主题**"，本项目解决"**用任何来源的包**"，并且：

- 自动对齐模块声明（教程要求主题包本身合规）
- 混搭 / 子集 / 快照恢复（教程没有）
- 跨平台探测与包体检（教程按品牌分文档）
- 把"做不到"的地方写清楚（教程里也没有的部分）

反过来，教程里有而本项目没有的：**免费试用付费主题**、**防回滚的具体操作**、
**澎湃版本与主题版本的严格对应表**。这些属于"授权与保活"，不是"投递技术"。
